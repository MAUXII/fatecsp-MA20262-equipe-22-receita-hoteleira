# Sazonalidade e Receita Hoteleira — EQP22

FATEC São Paulo · Microinformática Aplicada (ILP590) · 2º/2026 · Prof. Veríssimo
Equipe 22 (individual): Mauricio — RA 20482413101 · Tema: Turismo e Eventos

**Pergunta central:** Qual o impacto do comportamento sazonal na receita hoteleira?

Rede hoteleira fictícia com quatro hotéis em destinos de perfis diferentes (praia, serra, capital e cidade histórica), período de 01/01 a 31/12/2025.

Os dados brutos dos quatro hotéis e os cadastros de origem estão em `01-excel/dados_brutos/`.

## Como abrir

Excel 365 ou 2021 para Windows, com Power Query e Power Pivot. Os caminhos de origem ficam em parâmetros; em outro computador, ajuste:

- Etapa 2: `pPastaReservas`, `pArquivoExcel` e `pArquivoMetas`;
- Etapa 3: `pArquivoEtapa2`.

Depois, use Dados → Atualizar Tudo, na ordem Etapa 1 → Etapa 2 → Etapa 3.
